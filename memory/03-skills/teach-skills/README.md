# Teach Skills

## Purpose

This folder holds Teach Skill artifacts — authored Markdown notes defining skills, triggers, input/output schemas, and agent instructions.

No real Teach Skill is implemented by this scaffold phase. Templates are authorship aids only.

## Allowed content

- Teach Skill notes (after formal authorization)
- Skill taxonomy and classification metadata

## Forbidden content

- Actual Teach Skill files created by this phase
- Teach Skill Studio implementation
- Skills that claim AgentBridge authority
- Private personal notes
- Automation or generated state

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Teach Skill Studio is not implemented. Skills do not grant implementation authority.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
