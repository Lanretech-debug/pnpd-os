# Audit Patterns

## Purpose

This folder holds reusable audit patterns for Codex and governance review. Patterns define audit checklists, verification steps, and evidence requirements.

No actual audit pattern is created by this scaffold phase.

## Allowed content

- Audit pattern notes (after formal authorization)
- Audit checklist and verification templates

## Forbidden content

- Actual audit patterns created by this phase
- Patterns that claim Owner or Codex authority not yet authorized
- Private personal notes
- Automation or generated state

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Audit patterns are advisory governance aids. They do not replace Codex audit or Owner review.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
