# Implementation Patterns

## Purpose

This folder holds reusable implementation patterns for DeepSeek and future implementation agents. Patterns define implementation strategies, conventions, and delivery discipline.

No actual implementation pattern is created by this scaffold phase.

## Allowed content

- Implementation pattern notes (after formal authorization)
- Implementation strategy and convention documents

## Forbidden content

- Actual implementation patterns created by this phase
- Patterns that claim production or adoption readiness
- Patterns that claim AgentBridge authority
- Private personal notes
- Automation or generated state
