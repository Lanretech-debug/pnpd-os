# 03-skills — Skill Authoring Layer

## Purpose

This folder holds Teach Skills, prompt patterns, audit patterns, and implementation patterns. These are the artifacts of the PNPD Skill Authoring Layer.

No real Teach Skill is implemented by this scaffold phase. Templates are authorship aids only.

## Allowed content

- Teach Skill notes (after formal authorization)
- Prompt pattern notes
- Audit pattern notes
- Implementation pattern notes
- README files describing folder governance
- Template files as authorship aids (non-executable)

## Forbidden content

- Actual Teach Skill files created by this phase
- Teach Skill Studio implementation
- Private personal notes
- Automation or generated state
- Skills that claim AgentBridge authority or deployment authorization

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable. No private personal notes may be committed.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Teach Skill Studio is not implemented. Teach Skills are authored as committed Markdown under `03-skills/` using the proposed frontmatter. Skills do not grant implementation authority.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
