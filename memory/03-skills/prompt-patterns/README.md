# Prompt Patterns

## Purpose

This folder holds reusable prompt patterns for agent instruction. Patterns are authorship aids for consistent agent interaction.

No actual prompt pattern is created by this scaffold phase.

## Allowed content

- Prompt pattern notes (after formal authorization)
- Pattern taxonomy and classification metadata

## Forbidden content

- Actual prompt patterns created by this phase
- Patterns containing credentials or secrets
- Patterns that claim AgentBridge authority
- Private personal notes
- Automation or generated state

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Prompt patterns are authorship aids for agent instruction. They do not grant AgentBridge authority. They do not authorize automated prompt injection or runtime dispatch.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
