# 99-archive — Archived Notes

## Purpose

This folder holds archived notes — material that was canonical before archival, retained for history but no longer active.

No archive entry is created by this scaffold phase.

## Allowed content

- Archived canonical notes (after formal archival decision)
- Historical records with preserved provenance
- README files describing folder governance

## Forbidden content

- Archive entries created without formal archival decision
- Material made canonical through archival when it was not canonical before
- Private personal notes
- Automation or generated state

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable. Archived notes retain their provenance.

Archival does not make non-canonical material canonical. Archived material must preserve provenance.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Archive is for material that was canonical before archival. Archived notes are retained in repo history. No archive entry is created by this phase.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
