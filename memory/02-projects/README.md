# 02-projects — Project Memory

## Purpose

This folder holds project profiles, adoption notes, and project-specific knowledge. Each project occupies a subfolder under `memory/02-projects/<project-slug>/`.

No project-specific folders are created in this scaffold phase. No actual project profiles are created in this phase.

## Allowed content

- Project profile notes (after project adoption/profile authorization)
- Project adoption notes
- Project-specific knowledge entries
- README files describing folder governance

## Forbidden content

- Project-specific subfolders created by this phase (not yet authorized)
- Actual project profiles created by this phase
- Private personal notes (must not be committed)
- Binary attachments without explicit governance
- Automation or generated state

## Privacy and Git tracking

`project-governed`. May be committed or gitignored per project policy. Project memory becomes governed only through project adoption/profile authorization.

Private personal notes must not be committed.
