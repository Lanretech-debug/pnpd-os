# Owner Decisions

## Purpose

This folder holds Owner authorization records, final decisions, and governance approvals.

No actual decision record is created by this scaffold phase.

## Allowed content

- Owner authorization records (after formal authorization)
- Final governance decisions
- Merge and release authorizations

## Forbidden content

- Actual decision records created by this phase
- Decisions attributed to Owner without explicit Owner authorization
- AgentBridge authority claims
- Private personal notes
- Automation or generated state

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Owner is the final authority for all PNPD governance decisions. No agent may override Owner authority.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
