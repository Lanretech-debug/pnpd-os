# Hermes — Design Agent

## Purpose

This folder holds Hermes design verdicts, design handoffs, and design-phase records.

No actual handoff record is created by this scaffold phase.

## Allowed content

- Hermes design verdicts (after formal authorization)
- Design handoff notes to DeepSeek or Codex
- Design session records

## Forbidden content

- Actual handoff records created by this phase
- Hermes output that overrides Owner authority
- Duplicated or truncated session output reused from non-fresh sessions
- Private personal notes
- Automation or generated state

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Hermes remains design/recommendation only. Design output requires fresh session for PNPD phase authority.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
