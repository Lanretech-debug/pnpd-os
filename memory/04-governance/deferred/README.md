# Deferred Scope

## Purpose

This folder holds records of deferred work — items that are intentionally postponed and not active backlog.

No deferred scope record is created by this scaffold phase.

## Allowed content

- Deferred scope records (after Owner review)
- Deferral rationale and conditions for re-evaluation

## Forbidden content

- Deferred items described as active backlog or work-in-progress
- Deferred items described as eligible implementation
- Records that override the deferred governance boundary
- Private personal notes
- Automation or generated state

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Deferred work is not active backlog. Deferred items are recorded in the deferred work register. They must not be mistaken for work-in-progress, active backlog state, or eligible implementation.

Reference: `docs/pnpd/deferred-scope-reconciliation.md`.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
