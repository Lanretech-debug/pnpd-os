# Blocked Scope

## Purpose

This folder holds records of blocked work — items that require Owner-authorized Hermes design, missing evidence, or external authority before they can be unlocked.

No blocked scope record is created by this scaffold phase.

## Allowed content

- Blocked scope records (after Owner review)
- Dependency and blocker documentation

## Forbidden content

- Blocked items described as actionable or eligible implementation
- Records that override the blocked/unlocked governance boundary
- Private personal notes
- Automation or generated state

## Privacy and Git tracking

`repo-governed`. Committed, CI-visible, machine-readable.

## Authority and automation boundary

No automation is authorized. Owner remains final authority.

Blocked work is not eligible implementation. Blocked items require Owner-authorized Hermes design, missing evidence, or external authority before they can be unlocked.

Committed Markdown files are the source of truth. Obsidian is the human-facing editor and navigation interface only.

## Obsidian compatibility

Obsidian-compatible Markdown. No `.obsidian` directory is created.
