# TEMPLATE ONLY — Project Note

This template is an authorship aid, not an authoritative record.

No automation is authorized.

Owner remains final authority.

## Intended use

Use this template when creating a project profile, adoption note, or project-specific knowledge entry under `memory/02-projects/<project-slug>/`.

## Required fields

- `type`: `project-profile` or `project-adoption-note`
- `project`: stable project slug
- `phase`: associated PNPD phase if applicable
- `privacy`: `project-governed`
- `git_tracking`: `committed` or `gitignored` per project policy

## Content body

```markdown
# Project — <project-name>

## Classification

## Adoption status

## PNPD alignment

## Memory and knowledge

## Skills in use

## Governance notes
```

## Authority boundary

- Project notes are governed by the project's adoption profile.
- They do not grant PNPD authority over the project.
- Private personal notes must not be committed.
- Project memory becomes governed only through project adoption/profile authorization.

## Promotion or validation requirements

- Project profile adoption authorization.
- No private note commits without explicit Owner authorization.
