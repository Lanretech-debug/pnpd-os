### 5. Problem or opportunity

When agents or collaborators propose novel idea candidates using the 1R-A harness, every candidate reaches the Owner unfiltered. There is no lightweight pre-check to catch obviously malformed, duplicate, or out-of-scope candidates before Owner time is spent. A manual triage checklist would reduce Owner burden by catching low-quality candidates early without requiring automation, schema, or code.

---

### 6. Proposed idea

A single-page markdown checklist that a human reviewer (Hermes or a designated triage lead) can apply to each incoming novel idea candidate before it is forwarded to the Owner. The checklist would verify:

- all 24 harness output fields are present
- candidate ID format is valid
- baseline is current and canonical
- source signal is documented
- evidence classification is explicit
- rejected alternatives are present
- drift risks are identified
- recommended route is within allowed range
- stop condition is defined
- governance boundary phrases are used correctly

The checklist is a reference document, not a script. It requires no code, no schema, no validator, no CI, and no runtime.

---

### 7. Novelty claim

PNPD-OS currently has no idea triage document. The 1R-A harness defines the candidate output model but does not define an intake triage process. This proposal introduces a human-executed governance checklist that is novel within the PNPD-OS document set.

---

### 8. Usefulness claim

A manual triage checklist would:

- reduce Owner review time by filtering malformed candidates before Owner attention
- provide a consistent pre-review surface for Hermes or a triage lead
- serve as a lightweight teaching tool for new contributors learning the harness
- operate without any code, schema, validator, CI, or runtime change
- be fully reversible (delete the doc)

---

### 9. Beneficiary

- **Owner** — fewer low-quality candidates to review
- **Hermes** — structured pre-screen criteria for design evaluation
- **Contributors** — clearer expectations for candidate quality before submission
